# N-gram Histograms

Parallel implementation of n-gram (bigrams/trigrams) counting on text corpora using OpenMP.

Mid-term project for the **Parallel Programming** course - University of Florence.

## Features

- Sequential and parallel n-gram counting
- Multiple parallelization strategies (Document-Level TLS, Chunk-Based, Fine-Grained Locking)
- Performance benchmarking (speedup, efficiency, scaling)
- Frequency distribution and Zipf's Law analysis

## Quick Start

```bash
./run_benchmark.sh
```
